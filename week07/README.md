## 成果物

1. メールアドレスの確認（検証）方法

アカウントに登録したメールアドレスが有効であることを認証する手順です。プライマリメールアドレスの検証を行うことで、アカウントのセキュリティが強化され、パスワード紛失時のサポートやGitHubのより多くの機能にアクセスできるようになります。
• 手順1・設定画面を開く. GitHubの任意のページの右上隅にあるプロフィール写真をクリックし、メニューから [Settings] をクリックします。
• 手順2・メール設定へ移動する. 左側サイドバーの [Access] セクション内にある [Emails] をクリックします。
• 手順3・確認メールを送信する. 該当するメールアドレスの下に表示されている [確認メールの再送信]（英語表記の場合は Resend verification email）をクリックします。
• 手順4・メール内のリンクから認証を完了する. GitHubから届く確認メールを開き、メール内の認証リンクをクリックします。リンクをクリックするとGitHubダッシュボードへ遷移し、画面上部に確認完了のバナーが表示されます。
• 根拠となる公式ページ. メールアドレスを検証する - GitHubドキュメント

2. 別のメールアドレスの追加方法

コミット履歴の紐づけや通知の管理のために、アカウントへ複数のメールアドレスを追加する手順です。
• 手順・追加の流れ. 右上のプロフィール写真から [Settings] を開き、左側メニューの [Access] 内にある [Emails] を選択します。次に [メール アドレスの追加] 欄に入力して追加し、送信される確認メール内のリンクをクリックして検証を行います。必要に応じて、同ページからプライマリ設定を変更可能です。
• 根拠となる公式ページ. GitHub アカウントへのメール アドレスの追加 - GitHubドキュメント
