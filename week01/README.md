大学1年生です。 平均とはなにかを、150字程度で説明してください!
平均とは、複数のデータを平らにならした基準となる値のことです。 すべてのデータを合計し、そのデータの個数で割ることで計算できます。データ全体の傾向や中心的な水準をひと目で把握するために使われますが、極端に大きい数値や小さい数値（外れ値）に影響を受けやすいという特徴があります。
小学生にもわかるように教えてください!
平均（へいきん）とは、バラバラな数をみんな同じになるように、平らにならした数（基準になる数）のことです。
たとえば、4人でお菓子を「5個、3個、2個、6個」とバラバラに持っているとします。これを一度ぜんぶ集めて（合計16個）、4人に同じ数ずつ配り直すと、みんな「4個」ずつになります。この「4個」が平均です。
みんなで「同じにすること」と覚えるとわかりやすいですよ！
課題を30分で終えるため、「資料を読む・要点を整理する・確認する」に時間を分けてください。合計が30分になるようにしてください。
課題を30分で終わらせるための時間配分は、「資料を読む：15分」「要点を整理する：10分」「確認する：5分」がベストです。
大学の課題やレポートに集中して取り組める、最も効率的な配分です。
• 資料を読む（15分）：全体の半分を使って、まずはじっくり内容をインプットします。
• 要点を整理する（10分）：読んだ内容から、大事なポイントをノートやパソコンに書き出します。
• 確認する（5分）：最後に、誤字脱字がないか、課題の条件を満たしているかをチェックします。
