# Week 06: AIと成果物を作る

## 成果物

新入生の皆さん、ご入学おめでとうございます！この授業では、課題や学習のサポートとして生成AIを積極的に活用できます。アイデア出しやコードのヒント、文章の推敲など、自分の学びを深めるツールとしてぜひ役立ててください。
ただし、AIを使う際には大切なルールが2つあります。1つ目は、AIの回答をそのまま提出せず、必ず自分の目で内容や動作を確認することです。AIは時々もっともらしい誤り（ハルシネーション）を出すため、情報の正確性を確かめる力もこの授業で身につけましょう。
2つ目は、AIを使った際の簡単な利用記録をGitHubに残すことです。「どのツールで、どんな質問をし、結果をどう活かしたか」を数行で構いませんので、リポジトリのREADMEや指定ファイルにメモしてください。
AIを賢く使いこなしながら、楽しく実践的なスキルを磨いていきましょう！
